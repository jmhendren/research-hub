Privacy policy — assistant-claude

Effective 21 August 2026

assistant-claude is a personal, single-user application operated by John Hendren for his own use. The only Google account it accesses is the operator's own account.

What it accesses

With the operator's consent through Google OAuth, the application reads messages and labels in the operator's Gmail account, applies labels, and creates drafts. It does not send email.

How the data is used

Message metadata and content are used solely to sort the operator's mail into categories, summarize it for the operator, and prepare drafts for the operator's review. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and sharing

Data is processed on the operator's own computer and stored in the operator's private repositories. It is not sold, shared with third parties, or used for advertising. No other person has access to it.

Revoking access

Access can be withdrawn at any time at myaccount.google.com/permissions; stored tokens are then invalid.
