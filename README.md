# research-hub

AI infrastructure research index. Models, primers, memos, briefs.

Served as a static site via GitHub Pages at `hub.noldor.app` (custom domain) and `jmhendren.github.io/research-hub` (default).

`noindex, nofollow` on the meta — unlisted by design, small named audience.

## Structure

- `index.html` — the hub
- `primers/`, `memos/`, `models/` — child pages (added as artifacts are re-audited and HTML-converted)
- `CNAME` — custom domain anchor for GitHub Pages

## Updating

Edit `index.html` directly. New artifact pages drop into the relevant subfolder and get a card on the index. Status badges:

- **Live** — post-audit, click-through to the page
- **New** — recently published
- **Re-audit** — predates the current audit pipeline; in re-verification
- **Coming soon** — placeholder

## Build provenance

Source materials live in a private workshop and vault. This repo is the published surface only — redacted copies of underlying deliverables.
